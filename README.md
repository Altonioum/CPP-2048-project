# CPP-2048-project

The two codes in this github do the following:

1. 2048
The 2048 code enacts the game 2048 in the terminal. It uses the keys WASD to move the numbers as you try and make the number 2048. It has a save and load function along with a new game function for when you get put in a bad place.

2. Luhn Algorithm
The Luhn algorithm or Luhn formula is a simple check digit formula used to validate a variety of identification numbers. The purpose is to design a numbering scheme in such a way that when a human is entering a number, a computer can quickly check it for errors.
